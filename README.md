A first-light momentum bot for make.fun's "Pump.fun Paper Sprint: Any Bot Can Win" bounty. It paper-trades pump.fun bonding-curve coins on a 6-hour replay: it buys a brand-new coin only after its price has already risen 12% in its first few trades, rides it with a 20% trailing stop, and cuts it on a 25% hard stop or when it goes stale. Paper trading only — no real funds, no network, fully deterministic.

## Run it

```sh
node main.ts
```
